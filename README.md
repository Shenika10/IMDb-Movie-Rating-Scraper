# 🎬 IMDb Movie Rating Scraper

A Python-based web scraping application that extracts the Top 250 movies from IMDb, including movie names, release years, and ratings.

## ✨ Features
- Scrapes IMDb Top 250 movies.
- Extracts movie titles and release years.
- Collects IMDb ratings.
- Exports results into a CSV file.
- Stores 250 movie records.

## 🛠️ Technologies Used
Python | Selenium | WebDriver Manager | CSV

## ⚙️ How to Run

```bash
pip install selenium webdriver-manager
python main.py
```

The extracted movie details are saved in `imdb_top_250_movies.csv`.
